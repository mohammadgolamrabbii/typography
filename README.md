## 🌟 Overview
The **Open Typography Live Previewer** is a responsive, web-based typography testing and visualization platform engineered by **Mohammad Golamrabbii** for the **Open Typography Foundation**. It enables designers, developers, and institutions to test and download authentic, open-source typefaces directly inside the browser across **7 major global writing systems**.

## ⚡ Features
- 🎛️ **Live Real-Time Typing:** Test any custom phrase or sentence across all fonts simultaneously.
- 📐 **Dynamic Font Size Slider:** Adjust size from 16px to 72px on the fly.
- 🌐 **Instant Script Filtering:** Switch seamlessly between Japanese, Bengali, English, Arabic, Hindi, and German.
- 🏛️ **1-Click Permanent Download:** Direct permanent links to Archive.org lifelong preserved ZIP packages.
- 📱 **Mobile & Dark-Mode Optimized:** Built with Tailwind CSS and modern Web Components.
